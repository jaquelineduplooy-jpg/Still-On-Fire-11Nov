DEPLOY
======
1. Unzip the package. Upload/commit ALL contents to the repository
   that deploys https://still-on-fire.vercel.app, preserving the file layout.
2. Ensure Vercel deploys the project root containing index.html,
   vercel.json, api/photos.js, memory-reel-live/ and assets/.
3. Redeploy Production and wait until the deployment is complete.
4. Open https://still-on-fire.vercel.app/api/photos?config=1
   and confirm jsonpFeedUrl equals the new URL above. This proves
   that Vercel is running the updated website code.
5. Open https://still-on-fire.vercel.app/api/photos?health=1
   and look for ok=true and a positive count.
6. Open https://still-on-fire.vercel.app/memory-reel-live/diagnostics.html
   to verify the images themselves display and check their actual pixels.
7. Open https://still-on-fire.vercel.app/memory-reel-live/index.html?v=25-new-feed
   on the HD television and check the indicator for the FULL collection.

IF THE NEW SCRIPT IS NOT READY
===========================
Check the Google Apps Script deployment at the new link above with
?health=1 appended. If it returns SNAPSHOT_NOT_READY, in Apps Script
run installGalleryRefresh once and refreshGallerySnapshot once, then
confirm the deployment is the current version and accessible to Anyone.
If it returns a photo count but the reel cannot show the images,
the photographs may be private to Google accounts; listing file IDs
does NOT grant anonymous TV browsers permission to display them.
Do not change personal/family photo sharing permissions without consent.
