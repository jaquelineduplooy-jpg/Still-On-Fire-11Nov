What results mean

Healthy feed, photos visible: the website can retrieve the photo list and display the selected picture. The reel should show the full gallery after refreshing.

GOOGLE_ACCESS_DENIED, GOOGLE_RETURNED_HTML or SCRIPT_ERROR: Google Apps Script cannot serve the folder anonymously. Its owner must check folder access and deploy it as Execute as: Me, Who has access: Anyone.

PHOTO_URL_NOT_VIEWABLE: the list is reachable but the TV browser cannot open the photographs. Check Drive image sharing or provide full-resolution local copies.

GOOGLE_NETWORK or GOOGLE_TIMEOUT: the server cannot reach the Apps Script deployment. The Vercel Function Logs and Apps Script Executions will show more.

This diagnostic never displays an individual's photo filename or a Google account token. Save/share the diagnostic code rather than sensitive links.
